3D GAME MENU

遊びたいゲームを選んでください

ファイルを直接開いているため、ゲームが起動できません（ブラウザの制限で、別ファイルの JavaScript を読み込めないため）。
リポジトリの直下（how-games-work-ja/）で npm run play-3d を実行し、表示された URL（http://localhost:3000 など）を開いてください。
1

ホーンテッド・テキストアドベンチャー

選択肢を選んで、お化け屋敷から脱出する

1 / 2: 選ぶ
2

バーガー・タイピング

ランダムに出る具材を打って、15 秒以内にバーガーを完成させる

Enter: スタート / 英字キー: 打つ / r: タイトルへ
3

エレキシューティング

降りてくる敵を撃ち落とす。10 体倒せばクリア

Enter: スタート / a・d: 移動 / Space: 撃つ / r: タイトルへ

1 / 2 / 3 キーでも起動できます。ゲーム画面の左上の「Back」でこのメニューに戻ります。
