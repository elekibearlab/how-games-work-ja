# エレキシューティング

上から降りてくる敵 `V` を、自機 `A` の雷の弾 `ϟ` で撃ち落とすリアルタイムのシューティングです。<br>
敵を 10 体倒せばクリア、自機が敵に 1 回でも当たるとゲームオーバーです（下まで降りた敵は消えます）。

![左右移動と射撃で敵を10体倒す実行動画](images/play.gif)

## 起動

動作環境は [サンプル集の README](../README.md#動作環境) を見てください。<br>
リポジトリの直下で、次のどちらかを実行します。

```sh
# Python版の場合
python 06_cli_games/03_eleki_shooting/python/main.py

# JavaScript版の場合
node 06_cli_games/03_eleki_shooting/javascript/main.js
```

Enter を押さずにキーを読むため、エディタの「出力」パネルなどではなく、通常のターミナルから起動してください。

| キー  | 動作                                         |
| ----- | -------------------------------------------- |
| Enter | スタート（タイトル画面）                     |
| a / d | 左 / 右に 1 マス移動                         |
| Space | 弾を撃つ                                     |
| r     | タイトルに戻る（クリア・ゲームオーバー画面） |
| q     | 終了（タイトル・クリア・ゲームオーバー画面） |

## 講座との対応

| 回    | しくみ                 | このゲームでは                                                                                |
| ----- | ---------------------- | --------------------------------------------------------------------------------------------- |
| 第1回 | ゲームループ           | 入力 → 更新 → 描画 のくり返し。敵はキーを押さなくても降りてくる                               |
| 第2回 | デルタタイム           | 敵と弾の速さは「1 秒あたりのマス数 × `delta_time`」。位置は小数で持ち、描くときだけ整数にする |
| 第2回 | 時間を数える           | 敵の出現タイマー（`spawn_timer`）を `delta_time` で減らし、0 になったら敵を出す               |
| 第3回 | 毎フレーム見に行く入力 | `read_key()` は待たずに、押されたキーか空文字を返す                                           |
| 第4回 | ゲームの状態           | タイトル → プレイ中 → クリア / ゲームオーバー を `change_state()` で切り替える                |
| 第5回 | 乱数                   | 敵が出る列を `random.randrange()` で決める                                                    |

## 実装内容

#### ゲームの状態

今回のゲームでは「ゲーム状態(game_state)」を、ゲーム全体のデータ `Game` の中に持っています。<br>
各状態の種類は、1 本目と同じく定数として定義しています。

| 値（定数）              | 画面           |
| ----------------------- | -------------- |
| `GAME_STATE_TITLE`      | タイトル画面   |
| `GAME_STATE_PLAYING`    | プレイ中       |
| `GAME_STATE_GAME_CLEAR` | ゲームクリア   |
| `GAME_STATE_GAME_OVER`  | ゲームオーバー |

状態は必ず `change_state()` を通して切り替え、プレイ中に入るときの開始処理 `start_playing()` で自機・敵・弾・スコアを最初に戻します。

```text
TITLE ────→ PLAYING ──10 体倒した──→ GAME_CLEAR
  ↑             └───敵に当たった───→ GAME_OVER
  └─────────────────────────────────────┘
```

#### コードの流れ

`main()` のループ処理にて、入力 → 更新 → 描画 の流れで読んでいます。<br>
ループの形はバーガー・タイピングと同じ「時計つきのループ」で、プレイ中の更新 `update_playing()` を自機・弾・敵の「もの」ごとの関数に分けています。

```python
def update_playing(game, key, delta_time):
    # 自機・弾・敵の更新
    update_player(game, key)
    update_bullets(game, delta_time)
    update_enemies(game, delta_time)

    # 当たり判定
    hit_bullets_and_enemies(game)

    # ゲーム状態の判定
    if game.score >= GOAL_SCORE:
        change_state(game, GAME_STATE_GAME_CLEAR)
    elif is_player_hit(game):
        change_state(game, GAME_STATE_GAME_OVER)
```

| 関数                        | やること                                                                              |
| --------------------------- | ------------------------------------------------------------------------------------- |
| `update_player()`           | a / d で自機を左右に動かし、Space で弾を撃つ                                          |
| `update_bullets()`          | 弾を上へ進め、画面の上から出た弾を消す                                                |
| `update_enemies()`          | 出現タイマーが 0 になったらランダムな列に敵を出し、下へ進め、画面の下から出た敵を消す |
| `hit_bullets_and_enemies()` | 弾と敵の当たりを調べ、当たった弾と敵を消してスコアを増やす                            |
| `is_player_hit()`           | 自機と同じマスに敵がいるかを調べる                                                    |
| `draw()`                    | ゲームの状態に合わせて盤面を文字のマス目で描き、見出しをつけて描き直す                |

#### すり抜けない当たり判定

速い弾は 1 フレームで何マスも進むので、「同じマスにいるか」で調べると敵をすり抜けることがあります。<br>
このゲームでは、弾は上へ、敵は下へ進むことを使って「同じ列で、弾が敵の位置を越えたか（`bullet.y <= enemy.y`）」で調べています。

当たった弾と敵は、その場ではリストから消さずに `is_alive = False` の印を付けるだけにしています。<br>
リストを回している途中でそのリストから消すと、次に調べる要素がずれてしまうためです。印の付いた弾と敵は、`hit_bullets_and_enemies()` の最後でまとめて消します。

#### Enter を待たないキー入力

`terminal_input.py`（`terminal_input.js`）はバーガー・タイピングと同じものです（[説明](../02_burger_typing/README.md#enter-を待たないキー入力)）。<br>
矢印キーは OS ごとに届き方が違うので、移動は文字キーの `a` / `d` にしています。
